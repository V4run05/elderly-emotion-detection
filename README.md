# "I'm Fine": detecting hidden low mood in older adults

Older adults often answer "How are you?" with "I'm fine" even when they aren't. This project is
a voice companion they can talk to about anything; underneath, it compares **what someone says**
with **how they seem** (voice tone and facial expression). It alerts family when a pattern of "says fine, seems low" appears
over several days.

Cognitive Robotics course project. Laptop version runs today; Raspberry Pi hardware integration is next.
